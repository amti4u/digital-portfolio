# Портфолио Маргариты

React + Vite. Карточки работ на основе присланного ScrollStack из React Bits, с Lenis. Цвета и композиция основаны на выбранном референсе.

## Запуск

Node.js 20.19+ или 22.12+ и pnpm:

```sh
pnpm install
pnpm dev
```

## Сборка и Vercel

```sh
pnpm build
pnpm preview
```

Для Vercel: preset Vite, команда сборки `pnpm build`, выходная папка `dist`. Секреты, сервер и база данных для портфолио не нужны.

## Контент

- `src/main.jsx`: тексты, список проектов и Telegram-контакт.
- `src/style.css`: палитра, оформление и мобильная версия.
- `src/components/ScrollStack.jsx`: адаптация React Bits ScrollStack (https://reactbits.dev/components/scroll-stack). Исправлены измерения трансформированных карточек; добавлены обновление при resize и отключение эффекта при reduced-motion, на узких и низких экранах.
- `public/images`: реальные скриншоты трёх опубликованных сайтов. StudioBook и бот пока показаны подписанными схематичными иллюстрациями, не скриншотами реального интерфейса. Публичных ссылок на них нет.

Ссылки на сайты и Telegram открываются в новой вкладке. Шрифт Golos Text загружается из Google Fonts; при недоступности сети используется Arial. Превью проектов работают без обращения к исходным сайтам.
